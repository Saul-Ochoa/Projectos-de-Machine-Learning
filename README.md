# Projectos-de-Machine-Learning

Este repositorio reúne proyectos de Machine Learning organizados por tipo de aprendizaje: supervisado (regresión y clasificación), no supervisado (clustering, reducción de dimensionalidad), series de tiempo/forecasting, y deep learning. Cada proyecto sigue un ciclo completo: definición del problema, EDA, preprocesamiento, modelado, validación e interpretación de resultados, aplicando metodologías que uso en producción en el sector financiero (SARIMAX, XGBoost, LightGBM) sobre datasets públicos.
